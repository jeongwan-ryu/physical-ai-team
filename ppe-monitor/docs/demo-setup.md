# 시연 환경 기록 (A)

시연 당일 같은 환경을 다시 만들 수 있도록, 정한 값을 그때그때 채워 넣습니다.

## 장비와 네트워크

| 항목 | 값 |
|---|---|
| Wi-Fi (2.4GHz) | (SSID만 적기. 비밀번호는 적지 않음) |
| ESP32 IP (DHCP 예약) | `192.168.x.x` → `SOURCE=http://192.168.x.x/capture` |
| Pi IP | `192.168.x.x` |
| EC2 공인 IP | `x.x.x.x` → `SERVER_URL=http://x.x.x.x` |
| 집 공인 IP (보안 그룹 허용) | `x.x.x.x` (`curl ifconfig.me`) |

## 카메라 거치

| 항목 | 값 |
|---|---|
| 모니터와 카메라 사이 거리 | cm |
| 높이와 각도 | 모니터 정면 / 기울기 ° |
| 고정 방법 | (예: 삼각대, 테이프) |
| 찍히는 범위 | 대시보드의 YouTube 플레이어 영역이 화면에 꽉 차게 |

## 화면과 조명

| 항목 | 값 |
|---|---|
| 모니터 밝기 | % |
| 실내 조명 | (예: 천장등 켬, 커튼 닫음) |
| 브라우저 확대 비율 | % |
| `FIX_EXPOSURE` / `AEC_VALUE` | 0 / - (고정했다면 1 / 값) |
